# STEPANYAN IT GROUP — Website

Static multilingual website for GitHub Pages.

## Files
- `index.html` — page structure and content
- `style.css` — responsive design
- `script.js` — language switcher, dark/light mode, mobile menu and WhatsApp contact form

## Languages
Georgian, English, Armenian, Russian.

## Important
The site describes STEPANYAN IT GROUP as a small remote digital initiative. It does **not** claim a physical office, company registration, certifications, or a large team.

The starting price is presented as **10 GEL from** for a small one-page website. Adjust the price whenever your actual offer changes.

## GitHub Pages
Create a public repository and upload the three site files. Then:
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

GitHub Pages will publish the static site.
